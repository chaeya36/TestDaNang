# DaNang-Trip

다낭 여행 일정 및 가이드 앱입니다.

## 🚨 현재 이 화면(글씨)이 보인다면? 배포 설정이 필요합니다! 🚨

지금 보고 계신 화면은 앱이 아니라 **'설명서(README)'** 파일입니다. 
정상적인 여행 앱 화면을 보려면 GitHub 설정에서 **단 한 가지**를 변경해야 합니다.

### 🛠️ 1분 만에 해결하는 배포 설정 방법

1. 현재 화면 상단의 **Settings (톱니바퀴 아이콘)** 탭을 클릭합니다.
2. 왼쪽 메뉴에서 **Pages**를 클릭합니다.
3. 화면 중간의 **Build and deployment** 섹션을 찾습니다.
4. **Source** 아래의 드롭다운 메뉴를 클릭하고, `Deploy from a branch`를 **`GitHub Actions`**로 변경합니다.
5. 끝입니다! 이제 상단의 **Actions** 탭을 눌러보면 노란색 불빛이 돌며 앱이 자동으로 만들어지고 있을 것입니다.
6. 초록색 체크(✅)로 바뀌면 다시 접속해 보세요. 진짜 다낭 여행 앱이 나타납니다!
